# internlist — ระบบติดตามฝึกงานสหกิจศึกษา (SPU CWIE Internship Tracker)

ระบบแดชบอร์ดติดตามการยื่นฝึกงานสหกิจศึกษาแบบ Real-time เชื่อมต่อข้อมูลสองทาง (Two-Way Sync) กับ Google Sheet

## ✨ ฟีเจอร์หลัก
- **มุมมอง 2 คอลัมน์ (Manus Style)**: แสดงการ์ดบริษัทพร้อมข้อมูลครบถ้วน จัดแบ่ง 4 โซนการเดินทาง, เขตพื้นที่, สวัสดิการ, และเหตุผลที่เล็งไว้
- **ดรอปดาวน์เช็คลิสต์สถานะ (Interactive Checklist Dropdown)**:
  - 🎯 เล็งไว้เเต่ยังไม่ยื่น [Col P]
  - ✈️ ส่งใบสมัครเเล้ว [Col P]
  - 📞 โทรตามผลแล้ว [Col Q]
  - 💼 สัมภาษณ์ [Col R]
  - 🏆 ได้ที่เเล้ว [Col S]
  - ⚪ ปัดตก [Col J]
  - 🚫 ปิดรับสมัคร [Col N]
- **ระบบล็อกสถานะข้ามกลุ่มอัตโนมัติ (Mutual Exclusion)** & คำนวณความคืบหน้าลำดับสูงสุด
- **ป้องกันข้อมูลใน Col O (สนใจส่งMail)** ไม่ให้ถูกลบหรือเขียนทับ
- **ซิงก์ข้อมูลสองทางกับ Google Sheet**: อัปเดตผ่าน Local Server และ Google Apps Script ทันที

## 🚀 การรันในเครื่อง (Local Run)
```bash
# รันเซิร์ฟเวอร์ Python
python server.py
# เปิดบราวเซอร์ที่ http://localhost:3000
```
